# 売上・広告費 一元管理ツール

Amazon・楽天・Yahoo!ショッピング・公式サイト・卸など、**販路ごとにバラバラな売上と
広告費を 1 画面にまとめて見る**ための、PC 上だけで動くツールです。

- 各モールの管理画面からダウンロードした **CSV をそのまま読み込めます**
  （Shift_JIS / UTF-8、カンマ / タブ区切り、注文明細でも日別集計でも可）
- チャネル別の **純売上・広告費・広告費率・粗利・粗利率・ACoS・ROAS・客単価** を一覧
- 月次／日次の推移グラフ、Excel で開ける CSV 出力
- 卸や実店舗など CSV が無い販路は手入力
- **データは PC の中だけ**。外部サーバへの送信は一切ありません

---

## 1. インストール

必要なのは **Python 3.8 以降だけ**です。追加のライブラリ（pip install）は要りません。

### Windows

1. Python がまだ無ければ https://www.python.org/downloads/windows/ から入れます。
   インストーラの最初の画面で **「Add python.exe to PATH」に必ずチェック**を入れてください。
2. このフォルダ（`tools/sales-manager`）ごと、デスクトップなど好きな場所にコピーします。
3. **`start.bat` をダブルクリック**します。

### macOS

1. ターミナルで `python3 --version` と打って 3.8 以降が出れば準備完了です。
   入っていなければ https://www.python.org/downloads/macos/ から入れます。
2. このフォルダをコピーし、**`start.command` をダブルクリック**します。
   「開発元が未確認」と出たら、右クリック →「開く」を選んでください。

どちらの場合も、数秒でブラウザが開いて画面が表示されます。
自動で開かないときは <http://127.0.0.1:8787/> を手で開いてください。

### デスクトップにアイコンを置く

毎回フォルダを開かなくて済むよう、デスクトップに起動用アイコンを作れます。

- **Windows**: `create_shortcut.bat` をダブルクリック
- **macOS**: `create_shortcut.command` をダブルクリック

デスクトップに「売上・広告費 一元管理」というアイコンができます。
次回からはそれをダブルクリックするだけで起動します。

元のフォルダを移動・削除するとアイコンは動かなくなるので、移動したあとは
もう一度このスクリプトを実行してください。アイコンを消したいときは次のとおりです。

```
python3 create_shortcut.py --remove
```

終了するときは、開いている黒い画面（コマンドプロンプト／ターミナル）で
`Ctrl` + `C` を押すか、そのウィンドウを閉じます。

```
python3 server.py                 # 既定どおり起動
python3 server.py --port 9000     # ポートを変える
python3 server.py --no-browser    # ブラウザを自動で開かない
```

## 2. 使い方

### 2-1. CSV を取り込む

「データ取り込み」タブで、次の順に操作します。

1. **種類**（売上 / 広告費）と**チャネル**を選ぶ
2. モールからダウンロードした CSV を、点線の枠にドラッグ＆ドロップ
3. **列の対応付け**を確認する
   - よくある列名（「受注日」「売上金額」「販売手数料」など）は自動で埋まります
   - 空欄や間違いがあればプルダウンで選び直します
   - `*` が付いた項目（日付・売上／広告費）だけは必須です
4. 「取り込む」を押す

取り込みの設定（どの列をどこに割り当てたか）は、名前を付けて保存できます。
翌月からは保存した設定を選ぶだけで、同じ形の CSV をそのまま取り込めます。

#### 便利な指定

| 場面 | 操作 |
|---|---|
| 注文 1 件が 1 行の明細 CSV（Amazon の注文レポートなど） | 「同じ日付の行を合計する」を ON（既定）。日別に自動集計されます |
| 手数料や原価の列が CSV に無い | 「または 売上の ◯ %」に率を入力（例: 手数料 15%、原価 35%） |
| 1 行目が列名でない CSV（楽天 RMS など） | 「見出しの行番号」を実際の行に変更 |
| 同じ月をもう一度取り込み直す | 「同じチャネル・同じ期間の既存データを置き換える」を ON。二重計上を防げます |
| 間違えて取り込んだ | 「取り込み履歴」タブ →「取り消す」でその回の分だけ削除 |

`samples/` に各モールを模したサンプル CSV（Shift_JIS・TSV・全角￥表記を含む）を
入れてあります。まずこれで動きを確かめると分かりやすいです。

サンプルを消してしまった場合や、内容を差し替えて試したい場合は次で作り直せます
（乱数の種を固定しているため、何度実行しても同じ内容になります）。

```
python3 samples/make_samples.py
```

### 2-2. 手入力

卸・実店舗・請求書ベースの取引など、CSV が出せない販路は「手入力」タブから
登録します。月まとめで入れる場合は、その月の 1 日を日付にしてください。

### 2-3. 見方

| 指標 | 計算式 |
|---|---|
| 純売上 | 売上 − 返金 |
| 粗利 | 純売上 − 手数料 − 送料 − 原価 − 広告費 |
| 粗利率 | 粗利 ÷ 純売上 |
| 広告費率 | 広告費 ÷ 純売上 |
| ACoS | 広告費 ÷ 広告経由売上 |
| ROAS | 広告経由売上 ÷ 広告費 |
| 客単価 | 純売上 ÷ 注文数 |

入力していない費目は 0 として計算されます。原価を入れていなければ、粗利は
「原価を引く前の利益」になる点にご注意ください。

なお、注文数の列を対応付けていない CSV は **1 行 = 1 注文**として数えます
（卸の請求 1 本を 1 行で入れた場合、注文数は 1 になります）。

## 3. データの保管とバックアップ

- すべてのデータは `data/sales.db`（SQLite ファイル）1 つに入っています
- **バックアップはこのファイルをコピーするだけ**です
- 別の PC へ移すときは、フォルダごとコピーすれば設定も履歴もそのまま移ります
- Git には `data/` を含めない設定（`.gitignore`）にしてあります

## 4. セキュリティ

- サーバは `127.0.0.1`（自分の PC）だけを待ち受けます。同じ Wi-Fi の他の端末からも
  見えません
- 外部への通信は行いません。ログイン ID・パスワード・API キーは一切保存しません
- 扱うのは売上金額と広告費の集計値です。購入者の氏名・住所などの個人情報は
  取り込まない運用を推奨します（このツールは集計値だけで動きます）

## 5. 困ったとき

| 症状 | 対処 |
|---|---|
| `start.bat` が一瞬で閉じる | Python 未インストール、または PATH 未設定です。再インストール時に「Add python.exe to PATH」にチェックを |
| 文字が化ける | 取り込み画面に判定した文字コードが出ます。違っていれば CSV を UTF-8 で保存し直してください |
| 「日付を解釈できない」と出る | 日付の列の指定違いがほとんどです。プレビュー表で中身を確認してください |
| ポートが使用中 | `python3 server.py --port 9000` のように変更できます（自動で空きポートも探します） |
| 金額が合わない | 同じ CSV を二重に取り込んでいないか「取り込み履歴」を確認してください |

## 6. ファイル構成

```
tools/sales-manager/
├─ start.bat / start.command   起動用（ダブルクリック）
├─ create_shortcut.bat        デスクトップにアイコンを作る（Windows）
├─ create_shortcut.command    デスクトップにアイコンを作る（macOS）
├─ create_shortcut.py         上記の中身（Windows / macOS / Linux 共通）
├─ icon.ico / icon.png        アイコン画像
├─ server.py                   ローカル HTTP サーバ
├─ db.py                       SQLite への保存・集計
├─ importer.py                 CSV の文字コード判定・列の対応付け・集計
├─ static/                     画面（HTML / CSS / JS）
├─ samples/                    動作確認用サンプル CSV
│   └─ make_samples.py         サンプル CSV の生成スクリプト
└─ data/sales.db               データ本体（自動生成・Git 対象外）
```
